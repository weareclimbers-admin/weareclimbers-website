# 🎬 Script Vidéo Manifeste WeAreClimbers

**Date de création** : 19 Janvier 2026
**Durée cible** : 60-90 secondes
**Format** : Vertical (9:16) pour Instagram/TikTok + Horizontal (16:9) pour YouTube
**Objectif** : Créer un mouvement émotionnel, PAS vendre une app
**Ton** : Authentique, rebelle, pas corporate

---

## 🎯 OBJECTIF DE LA VIDÉO

### ✅ CE QU'ON VEUT
- **Créer une connexion émotionnelle** avec les grimpeurs qui galèrent
- **Challenger la culture toxique** de la performance à tout prix
- **Lancer un mouvement**, pas vendre un produit
- **Humaniser la marque** avec ton visage et ton histoire
- **Donner envie de rejoindre** sans parler de features techniques

### ❌ CE QU'ON NE VEUT PAS
- Une démo produit (0 screenshot app, 0 spec tech)
- Un ton corporate lisse (on veut du punch, de l'émotion)
- Une vidéo parfaite techniquement (l'authenticité > la perfection)
- Vendre le bracelet (juste mentionner discrètement)

---

## 📊 STRUCTURE NARRATIVE (3 ACTES)

```
ACTE 1 (0-20s) : LE PROBLÈME
→ Montrer la culture toxique de la grimpe actuelle

ACTE 2 (20-50s) : LA VISION
→ Proposer une alternative, notre philosophie

ACTE 3 (50-90s) : L'APPEL
→ Humaniser avec ton histoire, inviter à rejoindre
```

## 🎵 MUSIQUE & SOUND DESIGN

### **Acte 1 (0-20s) : Tension**
- Style : Électro minimaliste tendue, montée progressive
- BPM : 90-110
- Instruments : Basse lourde, percussions sèches, synth atmosphérique
- Références : "Unstoppable" (The Score), "Enemy" (Imagine Dragons)
- Sources gratuites :
  - Epidemic Sound (payant mais qualité pro)
  - Artlist (payant)
  - YouTube Audio Library (gratuit, filtre "Dark/Tension")

### **Transition (20-22s) : Respiration**
- Silence total sauf respiration humaine (la tienne)
- Enregistrer : Inspire profonde + expire lente
- Ajouter léger reverb (effet spatial)

### **Acte 2 (22-50s) : Inspiration**
- Style : Indie folk inspirant, guitare acoustique + cordes
- BPM : 80-95
- Instruments : Guitare fingerpicking, cordes douces, piano subtil
- Références : "Home" (Philip Phillips), "Holocene" (Bon Iver)
- Montée progressive de l'intensité

### **Acte 3 (50-90s) : Conviction**
- Style : Continuation acte 2 mais crescendo émotionnel
- BPM : Même tempo mais ajout de percussions progressives
- Climax au plan 13 (montage diversité)
- Fade out doux sur plan 14 (logo)

### **Références Musicales Précises**
- "Intro" - The xx (minimalisme électro tension)
- "To Build a Home" - The Cinematic Orchestra (émotion inspirante)
- "River Flows in You" - Yiruma (piano contemplatif)

### **SESSION 4 : Enregistrement Voix Off (2 heures)**

**Objectif** : Enregistrer ta voix proprement

**Matériel** :
- 🎤 Micro correct (AirPods Pro OK, Rode VideoMic better)
- 🏠 Pièce silencieuse (pas d'écho)
- 💻 Logiciel : Audacity (gratuit) ou Voice Memos (iPhone)

**Process** :
1. Lire le script 2-3 fois à voix haute (s'échauffer)
2. Enregistrer 3-5 prises complètes
3. Sélectionner les meilleures phrases de chaque prise
4. Exporter en WAV (meilleure qualité)

**Conseils** :
- Parle **lentement** (tu vas trop vite naturellement)
- **Articule** (surtout les consonnes)
- **Émotion** dans la voix (pas monotone)
- Bois de l'eau (voix hydratée = voix claire)

### **Étapes Montage (CapCut)**

#### **1. Importer les clips** (10 min)
- Tous les plans filmés
- Stock footage téléchargé
- Voix off enregistrée
- Musique choisie

#### **2. Timeline rough cut** (30 min)
- Poser tous les plans dans l'ordre du script
- Ajuster durées approximatives
- Vérifier flow général

#### **3. Synchronisation voix + image** (1h)
- Aligner chaque phrase voix off avec le bon plan
- Ajuster timing des plans (couper/rallonger)
- Transitions douces (crossfade 0.3s entre plans)

#### **4. Musique** (30 min)
- Importer les 2 musiques (Acte 1 + Acte 2/3)
- Ajuster volume (voix doit être audible)
- Couper musique pour transition (respiration)
- Fade in/out sur début et fin

#### **5. Texte & Logo** (30 min)
- Plan 14 : Logo WAC centré
- Texte : "We Are Climbers", "Pas une app. Un mouvement", etc.
- Animation simple : fade in progressif
- Police : Utiliser SYNE (ta font) si possible dans CapCut

#### **6. Color grading (optionnel)** (30 min)
- Acte 1 : Teintes froides (bleu/vert), contraste élevé
- Acte 2/3 : Teintes chaudes (orange/doré), luminosité +10%
- Uniformiser l'ensemble (pas de plan qui détonne)

#### **7. Export** (10 min)
- Format : 1080×1920 (vertical Instagram)
- ET 1920×1080 (horizontal YouTube)
- Bitrate : Élevé (qualité max)
- Format : MP4 (H.264)

**TOTAL MONTAGE** : ~3-4 heures (si première fois)
