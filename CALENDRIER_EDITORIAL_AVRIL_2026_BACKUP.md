Pour créer WAC, j'ai dû résoudre 3 défis techniques :

Aucune app d'escalade ne le faisait.

Pourquoi ? Parce que c'est complexe.

→ API Clue (si user utilise déjà)

→ Analyse corrélation cycle/performance
→ Conseils adaptatifs par phase

**3. Pas de classement toxique (tout en gardant des challenges)**

Comment proposer des challenges SANS créer de comparaison toxique ?

→ Challenges PRIVÉS (pas publics)
→ Objectifs de GROUPE (pas individuels compétitifs seulement)

Pas parce que c'est "sexy startup".
