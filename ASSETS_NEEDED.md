## 🎨 GUIDELINES CRÉATION VISUELS

### Couleurs à respecter (Charte graphique WAC)
- Vert principal : `#265335`
- Beige principal : `#F5ECE5`
- Orange secondaire : `#F67931`
- Beige secondaire : `#B19580`
- Beige clair secondaire : `#E6D5C7`

### Typographie
- **Titres** : Syne Bold, uppercase
- **Corps de texte** : Roboto Regular/Medium/Bold

### Style général
- Authentique, pas corporate
- Inclusif (représentation diversifiée genres, morphologies, niveaux)
- Ambiance escalade (indoor et outdoor)
- Bienveillant, pas compétitif

## 📦 FORMATS & OPTIMISATION

### Photos
- Format préféré : WebP (fallback JPG)
- Compression : 80-85% qualité
- Dimensions max : 2400px largeur pour photos pleine largeur

### Logos
- Format préféré : SVG (vectoriel)
- Fallback : PNG avec fond transparent
- Multiples tailles pour responsive

### Vidéos
- Format : MP4 (H.264)
- Compression : max 5MB pour vidéos de fond
- Prévoir image de fallback (poster)
