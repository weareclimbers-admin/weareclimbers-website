# 🎬 SCRIPTS REELS & VIDÉOS COURTES - WAC

**Projet** : We Are Climbers
**Objectif** : Scripts prêts à tourner pour Reels Instagram / TikTok
**Formats** : 15-60 secondes

---

## 🎯 PRINCIPES VIDÉOS WAC

### Règles d'or

1. **Sous-titres OBLIGATOIRES** (80% regardent sans son)
2. **Hook dans les 3 premières secondes** (sinon scroll)
3. **Authenticité > Production** (smartphone suffit, pas besoin de 4K)
4. **Message clair** (1 idée par vidéo, pas 10)
5. **CTA final** (enregistre, commente, suis)

### Style visuel

- **Lumière naturelle** (pas de ring light trop fort)
- **Cadrage simple** (visage centré ou règle des tiers)
- **Montage dynamique** (coupe toutes les 3-5 secondes)
- **Musique discrète** (voix prioritaire)

---

## 📋 STRUCTURE UNIVERSELLE D'UN REEL

### Timeline type (30 secondes)

| **Timing** | **Élément** | **Objectif** |
|------------|-------------|--------------|
| 0-3s | **Hook** (visuel + texte accrocheur) | Capter l'attention, éviter le scroll |
| 3-25s | **Corps** (3-4 points clés avec texte overlay) | Apporter de la valeur, éduquer, émouvoir |
| 25-30s | **CTA + Logo** (appel à l'action clair) | Conversion (enregistre, commente, suis) |

### Exemple appliqué

```
[0-3s] HOOK : "3 erreurs qui causent 90% des tendinites en grimpe ⚠️"
→ Visuel : Gros plan main avec bandage

[3-10s] Point 1 : "❌ Grimper sans échauffement"
→ Visuel : Clip grimpeur attaquant direct une voie

[10-17s] Point 2 : "❌ Augmenter le volume trop vite"
→ Visuel : Calendrier montrant progression trop rapide

[17-24s] Point 3 : "❌ Ignorer les signaux de ton corps"
→ Visuel : Grimpeur grimaçant de douleur

[24-30s] CTA : "Enregistre pour ne pas oublier 💾 | Logo WAC"
→ Visuel : Logo WAC + texte "We Are Climbers"
```

### Sous-titres : Absolument OBLIGATOIRE

**Outils auto-subtitles :**
- CapCut (gratuit, excellent)
- Runway (IA précise)
- Instagram (sous-titres auto depuis 2024, qualité moyenne)

**Style sous-titres WAC :**
- Police : Sans-serif simple (Arial, Helvetica)
- Couleur : Blanc avec fond noir semi-transparent
- Taille : Lisible (min 48pt)
- Position : Centre-bas (pas trop bas, couvert par UI Instagram)

### A/B Testing : Teste ces variantes

**Même contenu, 2 hooks différents :**

Version A : "3 erreurs qui causent la tendinite"
Version B : "Tu veux éviter la tendinite ? Arrête de faire ça."

→ Publie version A un lundi, version B le lundi suivant
→ Compare performances (reach, engagement)
→ Garde le format gagnant
